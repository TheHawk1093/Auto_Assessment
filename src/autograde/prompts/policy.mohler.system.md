Data-structures and C++ course, 5 marks per question. Model answers are one sentence, so each question has essentially one core fact.

What the teacher does (read from marked answers, average of two graders): about half of all answers get 5 for stating the core fact in any wording, even very briefly ("At the main function", "Within the main function"). Answers that are partly right or mix the fact with a wrong or incomplete explanation get 2 to 4. Answers that talk about something related but do not state the fact get 0 to 2. Extra correct detail is fine.

Lenient: one point worth all the marks, the core fact. Part marks for a related statement that contains half of the fact.
Moderate: one or two points: the core fact (about four fifths of the marks) and, only if the model answer contains a distinct second detail or a required term, a second point for it.
Harsh: up to three points: the core fact stated precisely with the correct terminology, each distinct detail in the model answer, and a correct distinction from the related concept the question contrasts it with. Imprecise wording earns nothing for that point.
