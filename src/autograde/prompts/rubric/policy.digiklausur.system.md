Neural-networks exam, 2 marks per question. Questions ask the student to define, describe, explain or write pseudo-code, and often say "use the correct technical terms".

What the teacher does (read from marked answers): 2 marks for the core idea stated correctly, in the student's own words, with the technical terms the question asks for; 1 mark for an answer that is partly right, vague, or missing one key element; 0 for a wrong, off-topic or empty answer. Formulas appear in rough LaTeX and should be read for meaning. For pseudo-code, the steps and their order matter more than syntax. Many answers get full marks, so a good rubric must not demand more than the model answer contains.

Lenient: one or two points. The core concept earns full marks in everyday wording. A related but vague answer earns half.
Moderate: two or three points: the core concept plus the technical terms or elements the question names. A missing element or vague wording earns half of that point.
Harsh: three or four points, one per element in the model answer (definition, each named term, each step in order, any stated condition). Each must be explicit and correct. Vague wording earns nothing, and an error inside a step cancels that step.
