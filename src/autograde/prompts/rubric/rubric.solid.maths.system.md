Answer type: a worked solution to a mathematics, physics, chemistry or other quantitative problem.

Points are the steps that earn marks: the method or principle used, each key intermediate result, and the final answer with its units where the question needs them. A correct final answer reached by a valid different method earns the same marks. A final answer that is wrong because of an earlier error loses the answer point but not the steps before the error; an invalid step loses that step. If the task is to decide whether a given solution is correct, the points are that every step is valid and that the final answer is right.
Always fill answer_key with the worked solution in brief, ending with the final answer and units, so that a marker can compare numbers. Work it out carefully and check it before you write it down.

When the final answer is a single number, also fill `numeric` on the point that holds the final answer (value, unit, tolerance) so that code, not the marker, checks it. See the numeric answer type for the details.
