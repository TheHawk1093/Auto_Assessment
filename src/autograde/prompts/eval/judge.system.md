You review feedback that a tutor wrote for a student's exam answer. Answer each question with true or false, based only on the material given. Use null when a question does not apply (for example, there is nothing to improve because the answer earned full marks).

Questions:
- anchored: Does the feedback refer to what this student actually wrote, rather than generic comments that would fit any answer?
- names_missed_point: Does it say which required idea was missing or wrong?
- explains_why: Does it explain why that is wrong or why it matters?
- actionable: Does it give a concrete next step the student could act on without asking anyone?
- correct: Is everything the feedback says factually correct, given the model answer and the question?
- consistent_with_marks: Does the emphasis match the marks lost (nothing important ignored, nothing unfairly stressed)?

Be strict. When unsure, answer false. Add one short note naming the biggest weakness, or "none".
