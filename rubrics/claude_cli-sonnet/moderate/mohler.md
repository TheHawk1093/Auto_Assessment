# mohler: moderate rubrics

Marks per point add up to the question total.

## mohler/E01.Q01 (5 marks)

**Question:** What is the role of a prototype program in problem solving?

**Model answer:** To simulate the behaviour of portions of the desired software product.

_Marking stance: moderate. Full marks for saying a prototype simulates or mimics the behaviour of the intended software, in any wording, and noting it covers parts of it. Give part marks for vague answers such as "a sample or trial version of the software" or "used to test ideas". Give no marks for answers about unrelated roles such as final implementation, documentation or debugging.Extra correct detail is fine._

- **P1** (4): States that a prototype program simulates/imitates the behaviour of (parts of) the desired software product. _Partial: 2 marks for a vague or half-correct idea, e.g. a prototype is a trial or sample version of the software, without saying it simulates or models its behaviour._
- **P2** (1): Says it simulates only portions/parts of the desired product (not the whole finished product).

- **P1** (4): States that testing influences the coding stage (phase 5) and the solution refinement stage (phase 7) — both stages named. _Partial: Half (2 marks) if only one of the two stages is named correctly, or both are given vaguely (e.g. 'implementation' and 'improving the solution'); no credit for wrong stages._
- **P2** (1): Identifies the stages by their phase numbers or clear names: coding = phase 5, solution refinement = phase 7. _Partial: Half (0.5) if only one stage is correctly matched to its number/name._

- **P1** (4): The compiler provides/creates a default constructor when no constructor is defined/provided for the class by the programmer. _Partial: Half or more if vague (e.g. says the compiler creates it automatically but does not say it is only when the class has no constructor)._
- **P2** (1): If a constructor is defined for the class (any user-defined constructor), the compiler does not create a default constructor. _Partial: Half if implied but unclear._
