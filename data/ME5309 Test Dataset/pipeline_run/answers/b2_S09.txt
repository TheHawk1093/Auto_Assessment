Q2(a). The model is second order, so I choose the position and velocity as states: x = [x1, x2]T = [θ,
θ˙]T, with input τ.
Rewriting Jθ¨ + bθ˙ + mgℓ sin θ = τ gives the nonlinear state-space model: x˙1 = x2, x˙2 = (1/J)(τ −
b x2 − mgℓ sin x1), i.e. x˙ = f(x, τ).
Equilibria for constant τ0 need x˙ = 0: the first equation gives x2 = 0, and the second then gives
mgℓ sin θe = τ0, i.e. sin θe = τ0/(mgℓ).
This has a solution only if |τ0/(mgℓ)| ≤ 1, so |τ0| ≤ mgℓ = 2.4525 N·m. For |τ0| < mgℓ there are
two equilibria per revolution (θe and π − θe); at |τ0| = mgℓ they merge, and beyond it the joint
cannot be held statically.

Q3(d). Advantage of the obsever: it uses the plant model and the applied input u, so its velocity
estimate has (almost) no phase lag; the 20 Hz filter on differenced data always delays by about
1/(2π fc) ≈ 8 ms. It can also reconstruct states that cannot be obtained by differencing (e.g.
disturbance, when augmented).
Filter is safer when the model is uncertain or changes (unknown payload, friction, contact, actuator
saturation): the obsever then gives a biased or poorly-behaved estimate while the model-free filter
still follows the measured data.
