Q2(a). The model is second order, so I choose the position and velocity as states: x = [x1, x2]T = [θ,
θ˙]T, with input τ.
Rewriting Jθ¨ + bθ˙ + mgℓ sin θ = τ gives the nonlinear state-space model: x˙1 = x2, x˙2 = (1/J)(τ −
b x2 − mgℓ sin x1), i.e. x˙ = f(x, τ).
Equilibria for constant τ0 need x˙ = 0: the first equation gives x2 = 0, and the second then gives
mgℓ sin θe = τ0, i.e. sin θe = τ0/(mgℓ).
This has a solution only if |τ0/(mgℓ)| ≤ 1, so |τ0| ≤ mgℓ = 2.4525 N·m. For |τ0| < mgℓ there are
two equilibria per revolution (θe and π − θe); at |τ0| = mgℓ they merge, and beyond it the joint
cannot be held statically.

Q2(c). At steady state θ˙ = 0 and θ¨ = 0.
A PD controler is stabel and its job is to drive (θd − θ) to zero, so θss = θd = 90°. The gravity term
only affects the transient. Hence the steady-state error is 0° and the joint does come to rest at θd.
Q2(d). Steady state: θ˙ = θ¨ = 0 and the control law gives τ = Kp(θd − θss) + mgℓ sin θss. Plugging
into the plant, mgℓ sin θss = Kp(θd − θss) + mgℓ sin θss, so Kp(θd − θss) = 0 and θss = θd:
stedy-state error is zero.
Pols: linearise the closed loop about θd. Before compensation, Jθ¨ + (b + Kd)θ˙ + (Kp + mgℓ cos θd)
δθ = 0, characteristic polynomial Jλ² + (b + Kd)λ + Kp + mgℓ cos θd. After compensation the added
term mgℓ sin θ cancels the plant's gravity term exactly, leaving Jλ² + (b + Kd)λ + Kp.
The two differ only by mgℓ cos θd, and for θd = 90° this is 2.4525 × 0 = 0. So the closed-loop
poles are unchanged at this operating angle. I should stress this is because cos 90° = 0; if θd
were, say, 60°, the compensation would raise the stiffness by 61.3 × 0.02... i.e. it would move the
poles.
Given: A = [0, 1; 0, −2], B = [0; 1], C = [1, 0], fs = 1 kHz so the sample time is T = 1/fs = 1 ms.
Q3(a). Reason 1 – noise amplification: the backward difference ωˆk = (θk − θk−1)/T has frequency
response (1 − e−jωT)/T, whose magnitude grows with frequency (≈ ω for small ωT), i.e. it is a
high-pass operation. Any noise on the encoder signal therefore appears in the velocity multiplied by
roughly 1/T = 1000 s-1, and can swamp the true velocity.
Reason 2 – quantisation: the encoder only reports integer counts, so Δθ is an integer multiple of the
count size q. Dividing by T = 1 ms gives velocity steps of q/T; for a 4096-count encoder q =
2π/4096 = 1.53×10-3 rad, so one step is 1.53 rad/s. At low speed the estimate flips between 0 and
one step (a noisy staircase), exactly where the damping term of the PD law is needed.
(A further, smaller issue is the half-sample delay of a backward difference, but the two reasons
above are the main ones.)

DC gain: 2(0.0099)/(1 − 0.9802) = 0.0198/0.0198 = 1 ✓.

Q3(d). Advantage of the obsever that no fliter of this kind can give: the observer is driven by both the
measurement y and the model with the actual input u, so it predicts the motion between samples.
The velocity estimat therefore has little or no phase lag. The low-pass filter on differenced data, by
contrast, always pays a lag of about 1/(2π fc) = 8 ms for its noise rejection, a trade-off it cannot
escape. In addition the observer gives all states, and can be augmented with a disturbance state
(e.g. unknown load torque) which no filter on θ can estimate.
Circumstance where the fliter is safer: when the plant model is poorly known or changes during
operation, for example an unknown payload, varying friction, contact with the environment, or
acuator saturation making u differ from the commanded value. The observer propagates the wrong
model so its estimate can be biased (and in the worst case unstable with the feedback loop),
whereas the model-free filter just smooths what the encoder actually measures.
Sampling at 1 kHz is fast compared with the 10 rad/s observer bandwidth, so discretisaton effects
are small.
Given: plant θ¨ + aθ˙ + cθ = b u with a = 2, c = 6, b = 1; controller u = Nff r − k1θ − k2θ˙.
Q4(a). Substituting u: θ¨ + (a + bk2)θ˙ + bk1θ = bNff r (the c term is the gravity load, handled
separately).
So s² + 4s + 2 = 0, giving s = −0.586 and s = −3.414. DC gain = bNff/(bk1) = Nff/2 = 1 ⇒ Nff = 2.
Q4(b). With the actual b = 0.75 and unchanged Nff = 8, k1 = k2 = 2, the closed loop becomes θ¨ + (a
+ bk2)θ˙ + (c + bk1)θ = bNff r, i.e. θ¨ + 3.5θ˙ + 7.5θ = 6 r.
For a unit step the steady state is found by setting derivatives to zero: 7.5 θss = 6 × 1, so θss =
6/7.5 = 0.8.
Tracking error = (r − θss)/r × 100% = (1 − 0.8) × 100 = 20%. A common mistake would be to say
the output falls by the same 25% as the acuator gain; that is wrong here, because b also appears in
the feedback stiffness c + bk1, which decreases from 8 to 7.5 and partially compensates. The poles
also change: s² + 3.5s + 7.5 → s = −1.75 ± 2.11j, still stable.
Q4(c). Substitutting u and differentiating: the integral term enters with a minus sign, so the
characterstic polynomial is s³ + (a + bk2)s² + (c + bk1)s − bKI.
Desired: (s + 4)(s² + 4s + 8) = s³ + 8s² + 24s + 32.
So 2 + k2 = 8 ⇒ k2 = 6; 6 + k1 = 24 ⇒ k1 = 18; −KI = 32 ⇒ KI = −32.
Q4(d). Suppose the closed loop is stable and r is constant. Then the state converges to a constant, so
θ˙ = θ¨ = 0 and, crucially, ξ˙ = 0 as well (ξ itself is constant at its final value ξss). From the
integrator equation ξ˙ = r − θ, we get r − θss = 0, i.e. θss = r.
Neither b nor c appears in this argument. They only influence the value of ξss needed to hold the
equilibrium (from the plant equation cθss = buss = b(−k1θss + KIξss)), and the pole locations, so the
zero error survives any error in the model parameters provided the loop stays stable (unlike the
feed-forward Nff scheme of part (b)).
Practical failure mode: integrator windup. If the actuator saturates (torque limit), the loop is
effectively open, the error stays non-zero and ξ keeps integrating to a huge value. When the
reference becomes reachable the stored integral forces a large overshoot and a long recovery.
Standard remedy: anti-windup, such as clamping the integrator when the acuator is saturated,
conditional integration, or back-calculation that feeds the difference between commanded and
saturated torque back to the integrator.
