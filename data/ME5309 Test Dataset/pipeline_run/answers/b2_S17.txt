Given: J = 0.02 kg·m², b = 0.05 N·m·s/rad, m = 1 kg, ℓ = 0.25 m, g = 9.81 m/s². So mgℓ = 1 × 9.81
× 0.25 = 2.4525 N·m (used throughout).
Q2(a). The model is second order, so I choose the position and velocity as states: x = [x1, x2]T = [θ,
θ˙]T, with input τ.
Rewriting Jθ¨ + bθ˙ + mgℓ sin θ = τ gives the nonlinear state-space model: x˙1 = x2, x˙2 = (1/J)(τ −
b x2 − mgℓ sin x1), i.e. x˙ = f(x, τ).
Equilibria for constant τ0 need x˙ = 0: the first equation gives x2 = 0, and the second then gives
mgℓ sin θe = τ0, i.e. sin θe = τ0/(mgℓ).
This has a solution only if |τ0/(mgℓ)| ≤ 1, so |τ0| ≤ mgℓ = 2.4525 N·m. For |τ0| < mgℓ there are
two equilibria per revolution (θe and π − θe); at |τ0| = mgℓ they merge, and beyond it the joint
cannot be held statically.

Q2(d). Steady state: θ˙ = θ¨ = 0 and the control law gives τ = Kp(θd − θss) + mgℓ sin θss. Plugging
into the plant, mgℓ sin θss = Kp(θd − θss) + mgℓ sin θss, so Kp(θd − θss) = 0 and θss = θd:

Poles: linearise the closed loop about θd. Before compensation, Jθ¨ + (b + Kd)θ˙ + (Kp + mgℓ cos

The two differ only by mgℓ cos θd, and for θd = 90° this is 2.4525 × 0 = 0. So the closed-loop

Given: plant θ¨ + aθ˙ + cθ = b u with a = 2, c = 6, b = 1; controller u = Nff r − k1θ − k2θ˙.
Q4(a). Substitute the control law into the plant: θ¨ + aθ˙ + cθ = b Nff r − b k1 θ − b k2 θ˙. Moving the
feedback terms to the left: θ¨ + (a + b k2) θ˙ + (c + b k1) θ = b Nff r.
Numerically, a + b k2 = 2 + 2 = 4 and c + b k1 = 6 + 2 = 8, so the characteristic equation is s² + 4s
+ 8 = 0. Roots: s = [−4 ± √(16 − 32)]/2 = −2 ± 2j. They have negative real parts, so the loop is
stable; ωn = √8 = 2.83 rad/s and ζ = 4/(2 × 2.83) = 0.707.
Transfer function from r to θ: T(s) = b Nff / (s² + 4s + 8). DC gain (s = 0): T(0) = Nff/8. For unity DC
gain, Nff = 8. (Note that this is larger than 1 because the gravity-related stiffness c and the
feedback k1 both resist the displacement.)
Q4(b). With the actual b = 0.75 and unchanged Nff = 8, k1 = k2 = 2, the closed loop becomes θ¨ + (a
+ bk2)θ˙ + (c + bk1)θ = bNff r, i.e. θ¨ + 3.5θ˙ + 7.5θ = 6 r.
For a unit step the stedy state is found by setting derivatives to zero: 7.5 θss = 6 × 1, so θss = 6/7.5
= 0.8.
Tracking error = (r − θss)/r × 100% = (1 − 0.8) × 100 = 20%. A common mistake would be to say
the output falls by the same 25% as the actuator gain; that is wrong here, becuase b also appears
in the feedback stiffness c + bk1, which decreases from 8 to 7.5 and partially compensates. The
poles also change: s² + 3.5s + 7.5 → s = −1.75 ± 2.11j, still stable.
Q4(c). Take the state z = [θ, θ˙, ξ]T. The plant gives θ¨ = −aθ˙ − cθ + b u with u = −k1θ − k2θ˙ + KIξ,
and ξ˙ = r − θ. With r = 0 (r only shifts the equilibrium) the closed-loop matrix is Acl = [0, 1, 0; −(c
+ bk1), −(a + bk2), bKI; −1, 0, 0].
Characteristic polynomial det(sI − Acl), expanding along the first row: s·[(s + a + bk2)s − 0] + 1·[(c
+ bk1)s + bKI] = s³ + (a + bk2)s² + (c + bk1)s + bKI. (Result)
Desiered poles −4 and −2 ± 2j: (s + 2 − 2j)(s + 2 + 2j) = (s + 2)² + 4 = s² + 4s + 8. Multiply by (s
+ 4): s³ + 4s² + 8s + 4s² + 16s + 32 = s³ + 8s² + 24s + 32.
Compare coefficients with a = 2, b = 1, c = 6: s²: 2 + k2 = 8 ⇒ k2 = 6. s¹: 6 + k1 = 24 ⇒ k1 = 18.
s⁰: b KI = 32 ⇒ KI = 32.
Chek: all coefficients of the desired polynomial are positive and (8)(24) = 192 > 32, so
Routh–Hurwitz confirms the three poles are in the left half plane ✓.
Q4(d). In stedy state ξ˙ = 0, so r − θss = 0 ⇒ θss = r for any b and c as long as the system is stable.
