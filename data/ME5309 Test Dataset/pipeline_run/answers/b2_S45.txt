Q3(a). Reason 1 – noise amplification: the backward difference ωˆk = (θk − θk−1)/T has frequency
response (1 − e−jωT)/T, whose magnitude grows with frequency (≈ ω for small ωT), i.e. it is a
high-pass operation. Any noice on the encoder signal therefor appears in the velocity multiplied by
roughly 1/T = 1000 s-1, and can swamp the true velocity.
Reason 2 – quantisation: the encoder only reports integer counts, so Δθ is an integer multiple of the
count size q. Dividing by T = 1 ms gives velocity steps of q/T; for a 4096-count encoder q =
2π/4096 = 1.53×10-3 rad, so one step is 1.53 rad/s. At low speed the estimate flips between 0 and
one step (a noisy staircase), exactly where the damping term of the PD law is needed.
(A further, smaller issue is the half-sample delay of a backward difference, but the two reasons
above are the main ones.)
Q3(b). The analogue prototype is the first-order low-pass H(s) = ωc/(s + ωc) with ωc = 2πfc = 2π × 20
= 125.66 rad/s. The bilinear (Tustin) transform replaces s by (2/T)(z − 1)/(z + 1) with T = 1/fs =
0.001 s.
Define a = ωcT/2 = 125.66 × 0.001/2 = 0.062832. Then H(z) = ωc / [(2/T)(z−1)/(z+1) + ωc] = a(z +
1) / [(1 + a) z − (1 − a)] = a(1 + z-1) / [(1 + a) − (1 − a) z-1].
Dividing through by (1 + a): a/(1 + a) = 0.062832/1.062832 = 0.059117 and (1 − a)/(1 + a) =
0.937168/1.062832 = 0.881767. Hence with u = differenced signal and y = filtered velocity: yk =
0.05912 (uk + uk−1) + 0.88177 yk−1. (Frequency pre-warping is neglected since fc ≪ fs/2.)
Verification of the DC gain: set u and y constant (z = 1): y = 2(0.05912)u + 0.88177 y ⇒ y(1 −
0.88177) = 0.11824 u ⇒ y/u = 0.11824/0.11823 = 1.000. In general H(1) = 2a/[(1 + a) − (1 − a)] =
2a/2a = 1 exactly, so the steady-state output equals the commanded input ✓.

Q3(d). Advantage of the obsever that no fliter of this kind can give: the observer is driven by both the
measurment y and the model with the actual input u, so it predicts the motion between samples.
The velocity estimat therefore has little or no phase lag. The low-pass filter on differenced data, by
contrast, always pays a lag of about 1/(2π fc) = 8 ms for its noise rejection, a trade-off it cannot
escape. In addition the obsever gives all states, and can be augmented with a disturbance state
(e.g. unknown load torque) which no fliter on θ can estimat.
Circumstance where the filter is safer: when the plant model is poorly known or changes during
operation, for example an unknown payload, varying friction, contact with the environment, or
actuator saturation making u differ from the commanded value. The observer propagates the
wrong model so its estimate can be biased (and in the worst case unstable with the feedback loop),
whereas the model-free filter just smooths what the encoder actually measures.

Q4(d). Suppose the closed loop is stabel and r is constant. Then the state converges to a constant, so
θ˙ = θ¨ = 0 and, crucially, ξ˙ = 0 as well (ξ itself is constant at its final value ξss). From the
integrater equation ξ˙ = r − θ, we get r − θss = 0, i.e. θss = r.
Neither b nor c appears in this argument. They only influence the value of ξss needed to hold the
equilibrium (from the plant equation cθss = buss = b(−k1θss + KIξss)), and the pole locations, so the
zero error survives any error in the model parameters provided the loop stays stable (unlike the
feed-forward Nff scheme of part (b)).
Practical failure mode: integrater windup. If the actuator saturates (torqe limit), the loop is
effectively open, the error stays non-zero and ξ keeps integrating to a huge value. When the
reference becomes reachable the stored integral forces a large overshoot and a long recovery.
Standard remedy: anti-windup, such as clamping the integrator when the acuator is saturated,
conditional integration, or back-calculation that feeds the diffrence between commanded and
saturated torque back to the integrator.
