Q2(c). At rest θ˙ = θ¨ = 0, so the PD torque must balance gravity: Kp(θd − θss) = mgℓ sin θss.
If θss = θd = 90° the left side is 0 but the right side is mgℓ sin 90° = 2.4525 ≠ 0: contradiction. So
the joint cannot rest at θd; the graviy torque needs a non-zero error to produce the holding torque.
Solve 50(π/2 − θss) = 2.4525 sin θss numerically: θss ≈ 1.5218 rad = 87.19°. Error ≈ 90° − 87.19°
= 2.81° (joint sags below θd).
Q2(d). With compensation, at rest: Kp(θd − θss) + mgℓ sin θss = mgℓ sin θss ⇒ θss = θd: steady-state
error = 0.
Closed loop: Jθ¨ + (b + Kd)θ˙ + Kp(θ − θd) = 0; gravity cancels. Without compensation the
linearised stiffness is Kp + mgℓ cos θd, and at θd = 90° cos θd = 0, so the stiffness is Kp either way.
Poles unchanged (specific to 90°; at other angles they would shift).

Q4(d). For a constant r, in steady state all derivatives vanish: ξ˙ = r − θss = 0 ⇒ θss = r, independent
of b and c; the closed loop only needs to be stabel so that a steady state exists.
Failure mode: integrator windup. When the actuator saturates the error persists, ξ keeps growing
and causes a large overshoot afterwards. Remedy: anti-windup (clamp the integrater, conditional
integration or back-calculation).
